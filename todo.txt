ДИАГНОСТИЧЕСКИЕ ПРИЗНАКИ (откуда известно о проблеме)
================================================================================

1. Хелпер goto_with_retry (3 попытки) создан именно потому, что страницы
   регулярно возвращают net::ERR_ABORTED — сервер прерывает соединение до
   отправки ответа. Симптом: воркеры Django заняты медленными DB-запросами
   или их недостаточно для очереди запросов.

2. Test suite 16 тестов = ~440 сек (~27 сек/тест при 2–5 страницах + форма).
   Ненормально медленно даже с учётом headless browser.

3. В тестах повсеместно используются wait_for_timeout(300–2000ms) —
   интерфейс долго реагирует на действия.

4. DOM-аудит выявил 404 на organizations-bg.jpg (OPFR) — лишний сетевой
   запрос при каждой загрузке страницы.

5. Select2 с нулевой высотой selection__rendered (Bug #2) — CSS-конфликт
   вызывает лишние repaint/reflow при инициализации виджетов.

ПРИОРИТЕТ 1 — BACKEND (наибольший ожидаемый эффект)
================================================================================

[ ] 1.1 Включить Django Debug Toolbar и замерить количество SQL-запросов
        на страницах: OPFR-список, Education-список, Foreign-список, резюме.
        Целевой показатель: не более 5–10 запросов на загрузку страницы.
        Команда для локальной установки:
          pip install django-debug-toolbar
          # добавить в INSTALLED_APPS + MIDDLEWARE + urls.py (только DEBUG=True)

[ ] 1.2 Добавить select_related / prefetch_related в QuerySet публичных списков.
        Пример (псевдокод):
          # Вместо:
          Organisation.objects.filter(...)
          # →
          Organisation.objects.filter(...) \
              .select_related('region', 'type') \
              .prefetch_related('contacts')
        Это устраняет N+1 паттерн (отдельный SQL на каждую карточку).

[ ] 1.3 Добавить page-level кэш для публичных read-only страниц.
        Страницы-кандидаты (публичные, данные меняются редко):
          - /registration/opfr_organisations/public-list/
          - /registration/training-course/public/list/
          - /registration/foreign-citizens-employment/public/list/
        Пример:
          from django.views.decorators.cache import cache_page

          @cache_page(60 * 15)  # 15 минут
          def opfr_public_list(request):
              ...

        Для страниц с фильтрами (уникальный URL на каждый набор параметров)
        кэшировать QuerySet через cache.get/set:
          cache_key = f"opfr_orgs_{request.GET.urlencode()}"
          qs = cache.get(cache_key)
          if qs is None:
              qs = list(Organisation.objects.filter(...).select_related(...))
              cache.set(cache_key, qs, 60 * 15)

[ ] 1.4 Проверить наличие DB-индексов на полях фильтрации.
        Поля для проверки (используются в WHERE по фильтрам на странице):
          - Organisation.name (фильтр по названию, OPFR)
          - Organisation.region (фильтр по региону, OPFR + Education)
          - TrainingCourse.region (Education)
          - TrainingCourse.start_date (Education, период обучения)
        Добавить если отсутствуют:
          name = models.CharField(db_index=True, ...)
          # или через миграцию:
          class Meta:
              indexes = [models.Index(fields=['region', 'name'])]

[ ] 1.5 Проверить настройки Gunicorn / uWSGI.
        Симптом ERR_ABORTED классически означает:
          а) workers < пиковая нагрузка (запросы ждут в очереди и таймаутятся)
          б) timeout меньше, чем время тяжёлого запроса
        Рекомендации:
          workers = 2 * CPU_cores + 1       # формула Gunicorn
          timeout = 120                      # секунды, не меньше макс. запроса
          worker_class = "gevent"            # или "gthread" для async I/O

[ ] 1.6 Включить persistent DB-connections (если не включено).
          # settings.py
          DATABASES = {
              'default': {
                  ...
                  'CONN_MAX_AGE': 600,  # секунды (0 = новое соединение на запрос)
              }
          }

ПРИОРИТЕТ 2 — FRONTEND (средний эффект, быстрые wins)
================================================================================

[ ] 2.1 Починить 404 на organizations-bg.jpg (OPFR).
        Файл отсутствует: https://gsz.gov.by/static/public/images/titles/organizations-bg.jpg
        Действие: загрузить файл на сервер ИЛИ убрать CSS-ссылку на него.
        Каждый посетитель OPFR делает лишний 404-запрос → засоряет логи +
        чуть замедляет загрузку (браузер ждёт ответа перед отрисовкой фона).

[ ] 2.2 Заменить полный FontAwesome на subset нужных иконок.
        Сейчас подключён полный пакет (~300 KB CSS + шрифтовые файлы).
        На проверенных страницах используются только 3 иконки:
          fa-filter, fa-caret-right, fa-forward
        Варианты:
          а) FontAwesome SVG + tree-shaking через webpack/vite (только нужные)
          б) Заменить иконки Unicode-символами и убрать зависимость совсем:
               fa-caret-right  → › (U+203A)
               fa-forward      → » (U+00BB)
               fa-filter       → SVG-иконка inline

[ ] 2.3 Добавить loading="lazy" на изображения ниже fold.
        На страницах-списках (OPFR, Education) карточки ниже первого экрана
        загружают изображения сразу при открытии страницы.
        Простое исправление в шаблоне карточки:
          <img src="{{ obj.image.url }}" loading="lazy" alt="...">
        Поддерживается всеми современными браузерами без JS.

[ ] 2.4 Перенести JS-скрипты в конец <body> или добавить defer/async.
        Скрипты в <head> без defer блокируют парсинг HTML — пользователь
        видит пустую страницу пока весь JS не загрузится и не выполнится.
          <!-- Вместо: -->
          <head><script src="bootstrap.js"></script></head>
          <!-- →: -->
          <script src="bootstrap.js" defer></script>
        Исключение: критические inline-скрипты (CSRF, начальный state).

[ ] 2.5 Добавить rel="noopener" на все target="_blank" ссылки.
        Без noopener открытая вкладка держит event loop родительской страницы
        активным — микроперформанс, но и security (Bug #6 в bug_reports_draft.txt).
        Глобальный фикс в base-шаблоне или через CSP:
          <a target="_blank" rel="noopener noreferrer" href="...">

[ ] 2.6 Исправить CSS-конфликт Select2 (нулевая высота __rendered).
        Bug #2 в bug_reports_draft.txt. Нулевой bounding box вызывает
        лишние repaint при инициализации виджета.
        Фикс в общей CSS-теме select2-bootstrap4:
          .select2-container--default
          .select2-selection--single
          .select2-selection__rendered {
            height: 100%;  /* добавить */
          }

[ ] 3.1 Запустить Lighthouse (Chrome DevTools → Lighthouse) на ключевых страницах
